# Word timestamps and speech review

Owner-requested on 2026-11-03: port Studio's timestamp-generation toggle/workflow, synchronized word highlighting and audio waveform views to hosted Speech Studio. This specification records that authorized scope before implementation; independent review remains required before merge. Spec lane: additive entity/API fields, regenerated timing identity and new UI.

## Contract

- Keep Gemini 3.8 Flash TTS as the speech default. Add an off-by-default word-highlighting generation setting. Enabling it runs OpenAI Whisper after speech, using the explicitly selected personal/service OpenAI key. Also support timestamp-only jobs for existing recordings (missing, all, selected, individual), primary/secondary voice and one/all languages. A timestamp-only job never regenerates audio.
- Reuse background queue, cancellation, scoped retry, progress, inspectable redacted logs and service allowances. Cache transcription by immutable audio bytes, locale, spoken-text prompt and model/version. Turning highlighting off never deletes recordings or existing timings. Failed timestamps leave successful audio available and retry without paying to regenerate it.
- Store word timings as immutable book-local JSON artifacts referenced by entry revisions; bind each to its audio file and spoken-text hash. Imported reader timecodes remain available, including existing workspaces without new metadata. Never display/export a timing record for changed audio/text. Restore audio and its timings together through history. Manual timing edits require an entry version and preserve history; regeneration protects them unless replacement is explicit.
- Validate provider results and manual input: finite nonnegative, ordered times, end >= start, within duration, bounded word counts/text. No key in URLs/logs. No user-controlled paths outside the book. Unsupported/oversized audio fails with an actionable message; valid existing audio remains. Retry an unsupported Albanian language hint once using auto-detection, matching Studio's behavior.
- Read-only plans show separate timestamp USD estimates ($0.006/minute), count, model and payer before confirmation. Combined speech+timestamps shows both components. Use measured WAV duration where available and clearly labeled text-based fallback otherwise; never present an unknown estimate as free. Charge service allowance for transcription attempts using a duration-derived character equivalent to bound long uploaded audio.
- Review recordings in an authenticated waveform player: play/pause, progress, seek by waveform/keyboard or word, playback speed, highlighted active word and visible timecodes. Use the actual timed transcript to avoid inventing alignment when spoken and display text differ. Missing timings show an explicit generate action, not fabricated precision. Allow editing word boundaries with version-checked save. Waveforms are decoded lazily in-browser using Web Audio; no new native/runtime dependency. History remains playable.
- Export the reader's timecode_output.json/timecode_voices.json contract for both narrators, enable the reader highlight feature when usable timings exist, and update recognized offline preload data. Preserve reader code and unrelated assets. Uploaded old readers are not upgraded.
