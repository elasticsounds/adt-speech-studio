# ADT Speech Studio

Standalone language and text-to-speech tools for exported ADT Studio reader ZIPs.

The first implementation is being developed as a reviewable pull request in this repository. It provides private accounts, Gemini/OpenAI speech, text normalization and updated reader ZIP downloads.
